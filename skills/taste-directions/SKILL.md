# Taste directions

Offer two or three real alternatives, and let the user pick. **Changes:** only `style/directions.html` and the `Direction` line in `style/brief.md`.

Read `style/brief.md`, `style/references/moodboard.md` if there is one, and this skill's `references/handbook.md`. In brand mode, skip this skill.

## Directions with character

Each one is a different answer to the brief's tension, not a variation in color. Write down the look a model would reach for first on this kind of product, and don't offer it unless the brief gives a reason. No two share a type pairing or a main hue.

For each: a name, a short paragraph that paints the picture, what it does with the tension, the trade-off it accepts, and the one thing people will remember.

## Show them

Build `style/directions.html`: each direction as a small real screen of this product, using its real words and assets, or a marked placeholder where an asset is missing. These are sketches to choose from, not the build. Show the page in the chat if your tool can, otherwise open it in the browser.

## Ask

Give your recommendation and its reason in a line. Then ask which they like most, with buttons in the inline view if it can send a reply, otherwise with the question tool. They can type a mix; if they do, check it still has one idea at its core.

Write the pick and why they chose it into the brief. Run alone, say that `/taste` writes the handbook from here.
